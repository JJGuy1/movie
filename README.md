- Генератор паролей, автор: Кирсанов Павел

Простое и удобное приложение для генерации безопасных паролей с возможностью настройки параметров и сохранения истории.

- Описание

Random Password Generator — это десктопное приложение с графическим интерфейсом, которое позволяет генерировать случайные пароли с настраиваемыми параметрами. Все сгенерированные пароли сохраняются в истории с возможностью последующего просмотра и управления.

- Основные возможности

  - Гибкая настройка паролей
  - Выбор длины пароля (от 4 до 32 символов)
  - Включение/выключение цифр
  - Включение/выключение букв (верхнего и нижнего регистра)
  - Включение/выключение специальных символов

  - Генерация безопасных паролей
  - Случайный выбор символов из выбранных наборов
  - Гарантированное включение символов из каждого выбранного типа

  - История паролей
  - Автоматическое сохранение всех сгенерированных паролей
  - Отображение параметров каждого пароля (длина, типы символов)
  - Фиксация времени генерации

  - Управление историей
  - Сохранение истории в JSON-файл
  - Загрузка истории из файла
  - Очистка истории

  - Удобство использования
  - Копирование пароля в буфер обмена одним кликом
  - Интуитивно понятный интерфейс

- Требования
- Python 3.6 или выше
- Стандартные библиотеки Python (tkinter, random, string, json, os), не требуют дополнительной установки
